# 术语表（Glossary）

open-labor 全域术语。首次出现用「中文（English, 缩写）」格式，后续用缩写或中文。

| 中文 | English | 缩写 | 定义 |
| --- | --- | --- | --- |
| 级别标尺 | tier axis | `tier_axis` | 跨范式矩阵纵轴对齐刻度（1-10），换算见 [tier-axis](tier-axis.md) |
| 范式 | paradigm | — | `hierarchical`（传统层级）或 `ai-native`，正交于组织 |
| 心智模型 | mental models | `mental_models` | 该层级默认为真的决策假设、首要指标、边界认知 |
| 场景 | scenario | — | 带约束的冲突 + 初阶/高阶解法 + 权衡（选 X 弃 Y，代价 Z） |
| 行为锚点 | behavioral anchor | `anchors` | 自评的 1-5 档可观察行为，5 档为机制化动作 |
| 自评维度 | assessment dimension | `dimension` | decision / boundary / leverage / loop / antipattern 五维 |
| 反模式 | anti-pattern | `anti_patterns` | 伪高阶表现、典型认知误区 |
| 业务周期 | version tag | `version_tag` | 语料的业务周期标记（增量扩张期 / 存量防御期等） |
| 来源标注 | source | `source` | 公开材料归纳 / 亲历者投稿 / 社区共识 |
| 交付闭环 | delivery loop | `delivery_loop` | 触发 → 动作序列 → 证据物 |
| 组织 | organization | — | 10 家：Alibaba / ByteDance / Tencent / Baidu / Anthropic / OpenAI / Kimi / MiMo / DeepSeek / Zhipu |
